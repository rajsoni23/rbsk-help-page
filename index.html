👋 Welcome

SHREE RBSK Automation is designed to simplify Student Registration and Child Screening on the RBSK Portal.

Upload your Excel file, start the automation, and let the extension handle repetitive work while improving speed and accuracy.

🚀 How To Use

  1. Install the SHREE RBSK Extension.
  2. Login using your approved account.
  3. Select Student Entry or Child Screening mode.
  4. Download the required Excel template.
  5. Fill all data correctly.
  6. Upload the Excel file.
  7. Click Start Automation.
  8. Wait until the automation completes.
